# Деньги и характер

Квиз для читателей финансового медиа: 5 вопросов, 6 результатов. Статический сайт без сторонних зависимостей и сбора ответов.

## Просмотр

Откройте index.html в браузере или запустите любой локальный сервер.

## Подсчёт

Каждый ответ даёт один балл персонажу. Результат определяется по доле баллов от доступных ответов этого персонажа (Матроскин: 5, остальные: 4). При равенстве побеждает персонаж из числа лидеров, выбранный в самом позднем вопросе. Порядок вариантов перемешивается один раз на прохождение; при возвращении назад ответ сохраняется.

## Шрифт

Сайт использует Suisse, если он установлен у читателя. Резерв: Arial, Helvetica, sans-serif. Для гарантированного отображения Suisse требуется подключить лицензированный веб-шрифт.

## Публикация

Vercel: статический проект, без команды сборки, корневая папка проекта.
