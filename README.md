# Деньги и характер

Квиз для читателей финансового медиа: 10 вопросов, 6 результатов. После ответов предлагает получить результат на email. Сервер сохраняет почту и персонажа в Supabase, затем отправляет письмо через Resend. Ответы в базе не хранятся. Настройка: [EMAIL-SETUP.md](EMAIL-SETUP.md).

## Просмотр

Рабочий прототип: https://financial-character-quiz.vercel.app.

Откройте index.html в браузере или запустите любой локальный сервер для просмотра интерфейса. Для отправки писем нужен серверный обработчик Vercel и переменные окружения — см. [EMAIL-SETUP.md](EMAIL-SETUP.md).

После десятого ответа открывается форма почты с обязательным согласием на сохранение email и результата. Подписки на рассылку нет. Кнопка «Поделиться» открывает системное меню отправки или копирует ссылку на квиз; если копирование недоступно, показывает ссылку для ручного копирования.

## Структура и проверка

- `app.js`, `index.html`, `style.css` — интерфейс.
- `quiz-data.js` — вопросы, описания персонажей и общий алгоритм подсчёта.
- `api/submit-quiz.js` — проверка ответов, сохранение в Supabase и отправка через Resend.
- `supabase/setup.sql` — закрытая таблица прохождений и ограничения частоты запросов.
- `.env.example` — пример имён настроек без настоящих ключей.

Тесты без обращения к почтовому сервису: `node --test tests/submit-quiz.test.cjs tests/share.test.cjs` (Node.js 22 или новее).

Секретные ключи задаются в настройках Vercel. Файлы `.env*` (кроме шаблона), `.vercel` и зависимости исключены из Git. Данные участников не входят в репозиторий.

## Подсчёт

Каждый ответ даёт один балл персонажу. Результат определяется по доле баллов от доступных ответов этого персонажа. При равенстве побеждает персонаж из числа лидеров, выбранный в самом позднем вопросе. Порядок вариантов перемешивается один раз на прохождение; при возвращении назад ответ сохраняется. Нажатие на ответ открывает следующий вопрос, а после десятого — форму email. Из формы можно вернуться к вопросам. Персонаж отображается только в письме.

## Шрифт

Сайт использует Suisse, если он установлен у читателя. Резерв: Arial, Helvetica, sans-serif. Для гарантированного отображения Suisse требуется подключить лицензированный веб-шрифт.

## Публикация

Vercel: без команды сборки, корневая папка проекта. Требуются переменные окружения из `.env.example` и таблица из `supabase/setup.sql`. Секреты используются только в серверном обработчике `api/submit-quiz.js`.
